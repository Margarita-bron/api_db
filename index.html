Events RESTful API

Управление сущностью событий (events) через стандартизированные HTTP-запросы с защитой по API-ключу.
1. Получение API-ключа
- Сгенерировать API-ключ и сохранить его.
- Ключ необходим для всех запросов к API: X-API-Key: ваш_ключ в заголовках.
2. Эндпоинты для работы с событиями:
  • GET /events — получить все события
  • GET /events/{id} — получить событие по id
  • POST /events — создать новое событие
    JSON body: {"title":"...", "date":"YYYY-MM-DD HH:MM:SS", "location":"...", "description":"..."}
  • PUT /events/{id} — обновить событие
    JSON body аналогичен POST
  • DELETE /events/{id} — удалить событие
3. Пример запроса в curl: 
curl -H "Content-Type: application/json" \
     -H "X-API-Key: ваш_ключ" \
     http://localhost/api_db/events
4. Коды ответов:
  • 200 OK — Успешные запросы
  • 201 Created — Создание новой записи
  • 400 Bad Request — Ошибка в параметрах запроса
  • 401 Unauthorized — Нет или неверный API-ключ
  • 404 Not Found — Запись не найдена
  • 500 Internal Server Error — Ошибка на сервере
5. Протестируйте через Postman/Insomnia:
Обязательный заголовок: X-API-Key
Content-Type: application/json для POST/PUT.
